Automated Isolation Forest Detection Pipeline
Autonomous Inference

Unsupervised anomaly detector evaluating eight-dimensional event profiles against the calibrated decision boundary (Cutoff Threshold: -0.012676).

⚙️ Automated Ingestion-to-Detection Pipeline
  1. Traffic Ingestion: Ingested network flows are partitioned into sliding temporal windows.
  2. Automated Feature Engineering: Event sets are transformed via TF-IDF weighting and basepoint similarity mappings into canonical 8-dimensional profile vectors (bp_01 to bp_08).
  3. Unsupervised Tree Traversal: Profiles stream directly into the trained 100-tree Isolation Forest to compute path lengths and anomaly scores.
  4. Zero-Day Verdict Generation: Flows exceeding calibrated cutoff τiso are flagged as Anomalous, defending against unknown exploits without manual tuning.

Project Overview & Academic Specification
College Capstone Project

AI-Based SIEM Cyber Threat Detection System using Artificial Neural Networks based on Event Profiles

Modern Security Information and Event Management (SIEM) systems are overwhelmed by massive network flow volume, resulting in extreme alert fatigue when traditional rule-based or per-packet inspection systems operate at scale. This project implements an end-to-end, privacy-preserving, high-throughput AI SIEM detection pipeline that operates on Event Profiles rather than inspecting raw payloads.
